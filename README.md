# InventoryPro
1. Extract this folder to C:\\xampp\\htdocs\\inventory_stock
2. Start Apache and XAMPP MySQL (port 3307) in XAMPP.
3. Import database.sql in http://localhost/phpmyadmin
4. Open http://localhost/inventory_stock/
5. Login: admin@inventorypro.test / password
Database config is in config/config.php. Coursework/local demo starter; not production-hardened.
